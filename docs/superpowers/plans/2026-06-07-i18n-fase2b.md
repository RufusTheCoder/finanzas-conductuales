# i18n Fase 2b (UI chrome) — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax.

**Goal:** Translate all learner-facing UI chrome (~200 hardcoded Spanish strings in `app.js`) to pt-BR via a new `ui.*` translation domain, with `{placeholder}` interpolation for dynamic strings, without regressing es-MX.

**Architecture:** Extend `t(key, fallback, params)` to fill `{name}` placeholders (backward compatible — content calls pass no params). A workflow inventories + extracts every chrome string into `ui.<area>.<slug>` keys (es value with `{placeholders}`) plus a verified old→new edit list. Subagents wire the sites; the es values are seeded; a translation workflow produces pt-BR; both langs seeded into `translations`. Fallback (the original es expression) keeps es-MX byte-identical throughout. Deploy in checkpoints.

**Tech Stack:** Vanilla ES modules (no build). Supabase REST + MCP. Node (ESM) scripts. Verification: node unit test, completeness greps, coverage SQL, `verify_esmx.mjs` (Playwright, `FORCE_LANG`).

- [ ] **Step 3: Update `t()` in `public/js/i18n.js`**

```js
export function t(key, fallback, params) {
  let v = store[key];
  if (v === undefined || v === null) v = (fallback !== undefined ? fallback : key);
  if (params && typeof v === 'string') {
    v = v.replace(/\{(\w+)\}/g, (m, k) => (params[k] !== undefined && params[k] !== null ? String(params[k]) : m));
  }
  return v;
}
```

## Task 2: Inventory + extract UI chrome (workflow)

**Files:** Create `scripts/ui_extract.json`, `scripts/ui_edits.json`

This is a **generation** step (judgment-heavy). Run a Workflow that fans out over `app.js` regions and, for EACH learner-facing Spanish chrome string, produces a verified extraction record.

- [ ] **Step 1: Run the inventory workflow**

Per-area agents (auth/nav, dashboard, journey tabs, bit quiz, sesgo modules, learn blocks, report wizard, next-steps, common buttons, toasts, rating labels). Each agent reads its region of `public/js/app.js` and returns records with this schema (one per chrome string):

```
{ key, es, fn, approxLine, oldSnippet, newSnippet, params }
```
Rules the agents follow:
- `key` = `ui.<area>.<slug>` (kebab-case, descriptive, unique).
- `es` = the current Spanish text with each interpolated variable replaced by a `{name}` placeholder (e.g. `Paso {step} de {total}`). Choose clear `{names}`.
- `oldSnippet` = the EXACT current substring in the file (the inline string/template fragment).
- `newSnippet` = `${t('<key>', \`<original es expression>\`, { <name>: <expr>, ... })}` (fallback = the ORIGINAL interpolated expression; params map placeholder names to the in-scope expressions). Static strings → no params arg.
- `params` = list of placeholder names (empty for static).
- Plurals: emit TWO keys (`<key>.one`, `<key>.other`); the `newSnippet` selects by count: `${t(n === 1 ? '<key>.one' : '<key>.other', <original>, { n })}`.
- Report conclusion phrases / embedded HTML: keep HTML literal in `es` with `{mech}`/`{pct}` placeholders; in `newSnippet`, pass the mechanism name ALREADY translated via the existing `report.mecanismo.<id>.name` key.
- EXCLUDE: anything already wrapped in `t(` (Fase 1b/2 content), `admin.js`, dev-only strings, console warnings, the `privacy.html` page (but DO include the "Aviso de Privacidad" link text). Translate only learner-visible chrome.
- A synthesis agent merges records, de-dupes keys, and flags collisions / risky sites.

Write the merged output to `scripts/ui_extract.json` (`{ key: es }`) and `scripts/ui_edits.json` (array of `{ key, fn, oldSnippet, newSnippet }`).

- [ ] **Step 2: Sanity-check the extraction**

Run (Node): confirm counts and uniqueness:

Expect: `keys` ≈ edits count, all edit `oldSnippet`s are non-empty. Eyeball ~10 records for correct keys/placeholders.

```js
// UI (ui.*) seeding helpers. Subcommands:
//   node scripts/ui_seed.mjs tsv            > scripts/ui_review.tsv   (es from ui_extract.json + pt from ui_ptbr.json)
//   node scripts/ui_seed.mjs rows <lang>    -> prints JSON rows [{key,lang,text,domain:'ui'}] for that lang (from extract/ptbr)
//   node scripts/ui_seed.mjs coverage       (DB ui.* es vs pt counts + key parity)
import { readFile } from 'node:fs/promises';
import { fileURLToPath } from 'node:url';

const TAB = '\t';
const esc = (s) => String(s ?? '').replace(/\\/g, '\\\\').replace(/\t/g, '\\t').replace(/\r?\n/g, '\\n');
const unesc = (s) => String(s ?? '').replace(/\\n/g, '\n').replace(/\\t/g, '\t').replace(/\\\\/g, '\\');
export function rowsToTsv(rows) {
  const header = ['key', 'es', 'pt'].join(TAB);
  return [header, ...rows.map(r => [r.key, esc(r.es), esc(r.pt)].join(TAB))].join('\n') + '\n';
}
export function parseTsv(tsv) {
  const [, ...body] = tsv.split('\n').filter(l => l.length);
  return body.map(l => { const [key, es, pt] = l.split(TAB); return { key, es: unesc(es), pt: unesc(pt) }; });
}
async function readJson(name) { try { return JSON.parse(await readFile(new URL('./' + name, import.meta.url), 'utf8')); } catch { return {}; } }

async function main() {
  const [cmd, arg] = process.argv.slice(2);
  const ex = await readJson('ui_extract.json');
  if (cmd === 'tsv') {
    const pt = await readJson('ui_ptbr.json');
    process.stdout.write(rowsToTsv(Object.keys(ex).map(k => ({ key: k, es: ex[k], pt: pt[k] ?? '' }))));
  } else if (cmd === 'rows') {
    const lang = arg;
    const src = lang === 'pt-BR' ? await readJson('ui_ptbr.json') : ex;
    process.stdout.write(JSON.stringify(Object.keys(ex).map(k => ({ key: k, lang, text: src[k] ?? ex[k], domain: 'ui' }))));
  } else if (cmd === 'coverage') {
    const { SUPABASE_URL, SUPABASE_ANON_KEY } = await import('../public/js/config.js');
    const want = new Set(Object.keys(ex));
    const get = async (lang) => new Set((await (await fetch(`${SUPABASE_URL}/rest/v1/translations?domain=eq.ui&lang=eq.${lang}&select=key`, { headers: { apikey: SUPABASE_ANON_KEY, Authorization: `Bearer ${SUPABASE_ANON_KEY}` } })).json()).map(r => r.key));
    const es = await get('es-MX'), pt = await get('pt-BR');
    const miss = (s) => [...want].filter(k => !s.has(k)).length;
    console.log(`ui coverage: want=${want.size} es=${es.size} pt=${pt.size} | es-missing=${miss(es)} pt-missing=${miss(pt)}`);
    process.exit(miss(es) + miss(pt) === 0 ? 0 : 1);
  } else { console.error('usage: tsv | rows <lang> | coverage'); process.exit(2); }
}
const isMain = process.argv[1] && fileURLToPath(import.meta.url) === process.argv[1];
if (isMain) main();
```
